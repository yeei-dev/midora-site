# midora.uk

Личный хаб Midora: Discord-боты, проекты и контакты.
Одна страница, тёмная минималистичная тема.

Стек: Next.js 15 (App Router) + React 19 + Tailwind.
Сборка статическая (`output: "export"` в `next.config.ts`), деплой на Vercel из ветки `main`.

## Команды

```
npm install
npm run dev     # локальная разработка, http://localhost:3000
npm run build   # статическая сборка в ./out
```

## Структура

- `app/page.tsx` — вся страница: обложка и секции «Боты», «Проекты», «Связь»
- `app/layout.tsx` — шрифт, метаданные, Open Graph
- `app/globals.css` — токены темы и стили строк списка
- `components/` — навигация, футер, строка-ссылка
- `data/site.ts` — весь контент: профиль, боты, проекты, ссылки

Чтобы поменять текст или добавить бота — правится только `data/site.ts`.

## Секреты

Токенов и паролей в репозитории нет. Токены Discord-ботов живут
только в переменных окружения на хостинге бота.
